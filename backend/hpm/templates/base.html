회의 전부터 후처리까지 E2E 시연

RunPod 확인 중

서비스 흐름

주제와 OCR 자료를 넣고, 안건을 선택한 뒤 준비자료를 만들고, 회의 중 챗봇과 회의 후 회의록 생성을 시연합니다.
1. 회의 전주제 입력, OCR 업로드, 기초안건 생성/선택, 준비자료 생성
2. 회의 중녹음 중 질문을 챗봇으로 확인
3. 회의 후STT 원문으로 회의록, 요약, Task 생성
4. 검색 기반회의록 본문만 청킹해 Qdrant 저장 후 질의 근거로 사용
